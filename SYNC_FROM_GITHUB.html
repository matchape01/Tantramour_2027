🔄 Sync depuis GitHub

Récupère tous les fichiers de données depuis GitHub dans un seul ZIP horodaté.

⚠️ Mode d'emploi :
1. Saisis ton token GitHub ci-dessous — il est mémorisé dans ton navigateur.
2. Clique ⬇ Télécharger le ZIP — tous les fichiers sont récupérés depuis l'API GitHub et compressés en un seul fichier.
3. Le ZIP est nommé automatiquement Tantramour_sync_AAAA-MM-JJ_HH-MM.zip.
4. Extrais le ZIP dans ton dossier Rapports/ en remplaçant les anciens fichiers.
